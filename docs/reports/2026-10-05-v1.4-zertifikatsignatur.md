# Bericht: v1.4 „Zertifikatsignatur" — 2026-10-05

## Thema und Ergebnis
v1.4 „Zertifikatsignatur" ist gebaut, im installierten Build abgenommen und als v1.4.0 auf GitHub veröffentlicht (Windows-Installer, macOS-DMG). CI ist auf beiden Plattformen grün, nachdem vier rote Läufe (#71–#74) behoben wurden; Ursache waren zwei Testfehler, nicht das Produkt.

## Geliefert
- Werkzeug „Zertifikat“ in Ausfüllen & Signieren: Siegel platzieren, bestätigen, signierte Kopie als neue Datei speichern; das Original bleibt bearbeitbar.
- Zertifikate selbst erstellen (3 Jahre) oder .p12/.pfx importieren; Verwaltung im Unterschriften-Dialog (Details, Fingerabdruck, Export, Löschen).
- Jede signierte PDF wird beim Öffnen geprüft: Banner, Signaturen-Dialog, „Signierte Version ansehen“, Unterzeichnende lokal vertrauen.
- Signierte Dokumente sind gesperrt; „Bearbeitbare Kopie…“ erzeugt eine unsignierte Kopie.
- Zitierstil standardmäßig APA 7 (deine Entscheidung).

## Im installierten Build abgenommen
Nur Windows 11, mit echter Maus und Tastatur, drei Runden. Geprüft wurden:
- Werkzeugleiste, auch bei 960×640.
- Zertifikat erstellen, Details, Löschen inklusive Neustart.
- Bestätigungsdialog, Signieren, gesperrter Tab, Menüsperre.
- Signaturen-Dialog, manipulierte Datei mit rotem Siegelrahmen, Klick aufs Siegel.
- „Signierte Version ansehen“, bearbeitbare Kopie.

## Nicht abgenommen

- Nur durch Tests belegt: Import einer .p12 (falsches/richtiges Passwort), abgelaufenes Zertifikat, zwei Signaturen, beschädigte Signatur, Nachträge nach dem Signieren, fehlender Schlüsselbund, reduzierte Bewegung.
- Gar nicht geprüft: Siegel in einem anderen PDF-Programm und im Ausdruck.
