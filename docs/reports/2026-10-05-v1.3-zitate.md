# Report: v1.3 "Citations" (Zitate) — 2026-10-05

## Topic and result
v1.3 "Citations" (FEEDBACK F15 C) is built, accepted and released as v1.3.0 on GitHub (Windows installer, macOS DMG). All 24 acceptance criteria of DESIGN §3.7 passed in the installed build, and the tester, security and designer reviews passed.

## Delivered
- Cite a selection (popover, Kommentieren tool, Ctrl/Cmd+Shift+C, Edit menu): Lavender highlight with an underline, plus a margin bubble with the quote, the printed page label and the short citation.
- Reference tab in Document Properties, prefilled from XMP, Info and page 1 (title, year, DOI), editable, saved in the PDF.
- APA 7, MLA 9, Chicago (author-date) and DIN ISO 690, in English or German. Copy a citation, the reference or the list; save the list as .txt, .html, .md, .ris or .bib.
- Coloured tags for comments and citations: picker, manager with undo, and a filter.
- Fixes: text selection on files with non-embedded fonts; empty annotation lists after deleting a page and saving.

## Accepted in the installed build
Windows 11 only, real mouse and keyboard, two rounds at 1280×800 and 960×640. Covered: all entry points, the citation before and after reopen, the bubble, the mini bar, the Reference tab, styles, copy/save including a write failure, tags, filter, empty state, read-only welcome sample.

## Not accepted
- macOS: CI tests only.
- Reduced motion: code and tests only.
- A permission-locked file was not tried (only the welcome sample).
- RIS/BibTeX: tests only.
- Other viewers and Word pasting were not checked.
