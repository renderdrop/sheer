# Report: v1.3 "Citations" (Zitate) — 2026-10-05

## Topic and result
v1.3 "Citations" from FEEDBACK F15 C is built, accepted and released as v1.3.0 on GitHub (Windows installer, macOS DMG). All 24 acceptance criteria of DESIGN §3.7 passed in the installed Windows build, and the tester, security and designer reviews passed.

## Delivered
- Cite a text selection (selection popover, Kommentieren tool, Ctrl/Cmd+Shift+C, Edit menu): a Lavender highlight with a 1 pt underline, and a margin bubble with the quote, the printed page label ("S. i") and the short citation.
- Reference tab in Document Properties, prefilled from XMP, the Info dictionary and page 1 (title, year, DOI); editable, with ordered authors; saved in the PDF.
- APA 7, MLA 9, Chicago (author-date) and DIN ISO 690 in English or German. Copy one citation, the reference or the whole list; save the list as .txt, .html, .md, .ris or .bib.
- Coloured tags for comments and citations: picker, manager (rename, recolour, delete with undo), and a Comments filter.
- Fixes: text selection fell short on files with non-embedded fonts; annotation lists were empty after deleting a page and saving.

## Accepted in the installed build
Windows 11 only, with the real mouse and keyboard, in two rounds at 1280×800 and 960×640, on a 4-page test file with page labels i, ii, 1, 2. Covered: all entry points, the citation look before and after save/reopen, the bubble, the mini bar, the Reference tab, style switching, copy and save of the list (including a forced write failure), tags, the filter, the empty state and the read-only welcome sample.

## Not accepted
- macOS: only CI tests, no build was operated by hand.
- Reduced motion was checked only in code and tests.
- A file whose permissions forbid changes was not tried; only the welcome sample was.
- RIS/BibTeX were checked only by tests. No check of how other viewers show the underline, or how Word pastes the HTML clipboard.

## Open

- An extra sixth swatch in the mini bar — small.

- Thumbnails ignore page labels — medium.
